# Encrypted Records Android App

This project was generated locally and is not hosted externally by default. The source code lives in this repository folder; share it by pushing to your own Git host or by zipping the folder for transfer.

## Open in Android Studio

1. Open Android Studio.
2. Select **File > Open**.
3. Choose this project directory (the folder containing `settings.gradle`).

## Share or download

- **Git hosting**: create a repository on GitHub/GitLab/Bitbucket, then add a remote and push this folder.
- **Zip archive**: compress the project directory and unzip it on your machine.
